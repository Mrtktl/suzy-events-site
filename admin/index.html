Yayın izni (tek seferlik)

GitHub'dan bir erişim anahtarı oluşturup buraya yapıştırın. Bu cihazda saklanır.

⚠ Güvenli bağlantı yok. HTTPS sertifikası tamamlandıktan sonra giriş önerilir.
  1. github.com/settings/personal-access-tokens/new
  2. Token name: suzy-admin   Expiration: No expiration (veya 1 yıl)
  3. Repository access → Only select repositories → suzy-events-site
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token deyip github_pat_… kodunu kopyalayın.
