Yayın izni (tek seferlik)

Değişikliklerin siteye otomatik yazılabilmesi için GitHub'dan bir erişim anahtarı oluşturup buraya yapıştırın. Bu cihazda saklanır, başka kimseyle paylaşılmaz.

  1. github.com/settings/personal-access-tokens/new sayfasını açın.
  2. Token name: suzy-admin   Expiration: No expiration (veya 1 yıl)
  3. Repository access → Only select repositories → suzy-events-site
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token deyip çıkan github_pat_… kodunu kopyalayın.
